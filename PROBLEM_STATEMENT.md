# Real Estate Email Automation Agent - Problem Statement

## Objective
Monitor multiple email accounts to automatically process property-related inquiries and extract structured data.

## Core Capabilities
1. **Multi-Mailbox Monitoring**: Support for 100+ accounts (Inbox & Sent Items).
2. **Property Link Detection**: Identify property links in email bodies.
3. **Automated Web Scraping**: Retrieve property listing details using Playwright/Selenium.
4. **Data Extraction & Structuring**: Extract fields like BHK, unit type, size, rent, and address.
5. **Daily Summary Reports**: Generate reports with newly found listings.

## Key Aspects to Consider
- **GenAI**: Use AI tools for meaningful output but validate logic manually.
- **Programming**: Clean, modular, reusable code with error handling and logging.
- **Functional Implementation**: Proper backend data flow, DB, and API.
- **Stack**: Backend (Node.js/Express/TS), Frontend (React Native Expo), Database (MongoDB).

## Deliverables
- Backend logic (API, Services, DB).
- Frontend App (Dashboard, Listings).
- Flow Diagram and Documentation.
